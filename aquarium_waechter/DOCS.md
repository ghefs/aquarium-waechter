# Aquarium-Wächter

🐠 **Bring dein Aquarium auf das nächste Level.**

Die vollständige Anleitung (Installation, Telegram, Push an die HA-App, Steckdosenleisten,
Überwachung einstellen) steht auf GitHub:
**https://github.com/ghefs/aquarium-waechter/wiki** – dort auch alle Entitäten und
Beispiele für eigene Automationen.

## Kurz

1. Im Reiter **Konfiguration** die ProfiLux-Geräte eintragen (Name und IP-Adresse) → Add-on starten.
2. In der Seitenleiste das Dashboard **Aquarium** öffnen – Werte und Einstellungen.
3. Alarm aufs Handy: Einstellungsseite → **Alarm aufs Handy** → Handy einschalten,
   dann **„Test-Alarm senden“**.
